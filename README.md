# NexusAI (Frontend-only with Puter.js)

React PWA + Capacitor scaffold for a controlled AI social automation system using Puter.js as the backend layer.

## Highlights
- Puter.js auth, AI, KV, and FS integration points
- Multi-step onboarding + brand kit persistence
- Controlled generation pipeline: generate -> validate -> human approval
- Ayrshare publish service integration stub
- Browser-native video engine (Canvas + MediaRecorder)
- PWA manifest + service worker shell caching

## Run
1. `npm install`
2. `npm run dev`
3. `npm run build`

> If your environment blocks npm registry access, dependency install will fail until policy/network is opened.
